How to Test Real Phone Calls on Your Personal UAE Mobile

When you want to make your physical mobile phone ring before connecting RAKEZ's Genesys trunk, follow these 4 steps:

Step 1: Verify Your UAE Number on Twilio (5 mins)

In a free Twilio trial account, open Phone Numbers → Manage → Verified Caller IDs and verify your personal UAE mobile (`+971 5x...`) via SMS OTP.

Step 2: Expose Local Port 8000 via ngrok (2 mins)

Run ngrok http 8000 in your terminal so Twilio Media Streams can stream bidirectional voice audio to your orchestrator.

Step 3: Set Environment Variables
export TWILIO_ACCOUNT_SID="ACxxxx..."
export TWILIO_AUTH_TOKEN="xxxx..."
export PERSONAL_VERIFIED_CALLER_ID="+97150xxxxxxx"
export AZURE_OPENAI_ENDPOINT="https://your-uaenorth.openai.azure.com/"
Step 4: Run the Python Orchestrator

Run py voice_ai_orchestrator_prototype.py. The built-in UAE compliance guard ensures personal Caller IDs only dial whitelisted test phones.
