How We Make the Voice Sound 100% Human

4 architectural pillars that eliminate the traditional "robotic IVR" feel for RAKEZ investors:

1. Expressive Neural HD Voices (UAE North)

Instead of flat text-to-speech, production calls use Azure OpenAI Realtime Speech or Azure Neural HD voices hosted in Dubai (`uaenorth`) with natural breathing, warmth, and conversational inflection.

2. Sub-500ms Sentence-Boundary Streaming

Noura begins speaking the first clause as soon as the AI generates 5 words—matching human turn-taking speed so there is never an awkward 3-second robotic pause.

3. Conversational Filler Phrases During CRM Lookups

While querying Portal 360 APIs, Noura naturally says "Let me check your Portal 360 profile real quick..." instead of leaving dead air on the line.

4. Instant Interruption Handling (Barge-In)

If an investor speaks mid-sentence, Voice Activity Detection (Silero VAD) stops audio playback within 50ms and listens immediately—just like a human Relationship Manager.

How to Test Real Phone Calls on Your Personal UAE Mobile

When you want to go beyond this web simulator and make your physical mobile phone ring before connecting RAKEZ's Genesys trunk, follow these 4 steps:

Step 1: Verify Your UAE Number on Twilio (5 mins)

In a free Twilio trial account, open Phone Numbers → Manage → Verified Caller IDs and verify your personal UAE mobile (`+971 5x...`) via SMS OTP.

Step 2: Expose Local Port 8000 via ngrok (2 mins)

Run ngrok http 8000 in your terminal so Twilio Media Streams can stream bidirectional voice audio to your orchestrator.

Step 3: Set Environment Variables
export TWILIO_ACCOUNT_SID="ACxxxx..."
export TWILIO_AUTH_TOKEN="xxxx..."
export PERSONAL_VERIFIED_CALLER_ID="+97150xxxxxxx"
export AZURE_OPENAI_ENDPOINT="https://your-uaenorth.openai.azure.com/"
Step 4: Run the Python Orchestrator

Run python3 voice_ai_orchestrator_prototype.py. The built-in UAE compliance guard ensures personal Caller IDs only dial whitelisted test phones.
